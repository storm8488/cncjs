# Inventaire des commandes machine de la page réelle

Phase 1 (audit) du lot « refonte » de CNCjs Touch, 2026-11-15. Base : branche `feat/refonte-ui` à `3049a0e4` (+ prompt `c35c9587`), page `examples/cncjs-touch/touch/index.html`, cache `v2u`.

C’est la colonne « ancien » de la table « ancien → nouveau » de `SURETE.md` (§ 5.5 du prompt de mission) : pour chaque élément de la page qui envoie quelque chose à la machine ou change un réglage de la machine ou du serveur, ce qui part, ce que le serveur en fait, ce qui finit sur le port série, les gardes et les tests. Les mêmes lignes sont dans `commandes-machine.json` (champ `lignes`, un objet par ligne, avec `selecteur`, `action`, `operation`, `envoi`, `serie`, `gardes`, `tests`) pour un test « ancien → nouveau ».

Ce document n’est pas une chasse aux bugs : ce qui m’a paru faux en passant est rangé à part (§ Remarques), sans preuve.

## Légende

- Références en petit : `p/` = `examples/cncjs-touch/touch/`, `s/` = `src/server/services/touch/`, `api/` = `src/server/api/`, `Grbl` = `src/server/controllers/Grbl/GrblController.js`, `CNCEngine` = `src/server/services/cncengine/CNCEngine.js`. Tests : `test-*.cjs` = `examples/cncjs-touch/`, `s/__tests__/` = tests Jest du service.
- Rendu : v1 (Éco, RT, ou Surface avant connexion) ; v2 (`body.perf-v2`). Une seule page sert les deux.
- « Relais » : le bouton visible clique un bouton caché (`#job-load`, `#job-start`, `#job-pause`, `#job-resume`, `#job-stop`, cachés dans Fichiers par `p/ui-2027.css:317` sauf `#job-load`), qui seul appelle le serveur.
- Port série : ce que `GrblController` écrit finalement ; `0x..` = octet temps réel ; `!` feed hold ; `~` reprise de cycle.

## Chemin commun de `/api/touch-job`

- **Requête** : `job-controls.js` `api()` envoie `POST <apiBase>/touch-job` avec `Authorization: Bearer <jeton CNCjs>`, délai 30 s (zéro Z plaque 180 s, palpage au bloc 270 s). Le corps reçoit toujours l’enveloppe `port`, `generation`, `transportId` (si le flux est ouvert), `clientId`, `clientLabel`. <sub>p/job-controls.js:151-177, p/job-controls.js:496-508</sub>
- **Exigences de la page** (`run()`) : état de moins de 3 s ; `prepare`, `start`, `resume`, `macro`, `override`, `unlock`, `home`, `spindle`, `readSettings`, `set-origin`, `machine`, `blockProbe` et `motion` (sauf `jog-stop`) exigent aussi la generation et le flux ouvert. Si l’état est perdu, Pause et Arrêter partent quand même, sans flux, vers le dernier contrôleur vu occupé (`halt`). <sub>p/job-controls.js:496-502, p/job-controls.js:389-392</sub>
- **Serveur** : `api.touch.js` `authorized` (session, service démarré) → `touch.action` → `job-service.js` `perform` ; réponse `{message, …, snapshot}` ; un refus porte `message`, et `code` / `params` / `reasons` pour les codes `ETOUCH_*`, `owner` pour `ECONTROL` ; statut `err.status` (409) ou 400 par défaut. <sub>api/api.touch.js:19-29, api/api.touch.js:61-85</sub>
- **Confirmation en deux temps** : `prepare` rend un ticket (nonce, 15 s, lié au flux, un seul par contrôleur), la page ouvre `#job-dialog` (case + Confirmer, compte à rebours) ; le second temps renvoie `{action: <opération>, nonce}` et le serveur refait les gardes. Le zéro de travail a son propre dialogue (`#real-motion-ticket`). <sub>s/job-service.js:1678-1738, p/job-controls.js:528-595</sub>
- **Bail de pilotage** : les actions gardées (`load`, `prepare`, `start`, `resume`, `macro`, `override`, `unlock`, `home`, `spindle`, `zeroZ`, `blockProbe`, `readSettings`, `set-origin`, `machine`, `motion` sauf `jog-stop`) sont refusées (409 `ECONTROL`) si un autre appareil pilote ; `pause`, `stop`, `spindleStop`, `settings`, `resumePlan`, `check`, `control`, `jog-stop` sont libres. <sub>s/job-service.js:169-173, s/control.js:36</sub>
- **Contrôleur** : `unlock` → `$X` ; `homing` → `$H` ; `reset` → `0x18` ; `jogCancel` → `0x85` ; `feedhold` et `gcode:pause` → `!` ; `gcode:resume` → `~` ; `gcode` → file CNCjs (une ligne après chaque `ok`) ; `gcode:start` → le sender envoie le programme ; `gcode:load`, `feeder:stop`, `gcode:stop` (sans `force`) n’écrivent aucun octet. <sub>Grbl:1365-1637</sub>
