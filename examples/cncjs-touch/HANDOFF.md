9. Supervised validation of the 2026-10-18 features on the machine (LUNYEE 4040 Nova, Grbl_ESP32 1.3a), in this order, with a hand on the emergency stop and the spindle off until the last step. Everything below was only run against the Grbl 1.1h simulator.
   1. **Air cut first.** Home, set a work origin high above the table (Z zero 30 mm above the bed, no stock), load a short program with `T1 M6` at the start and `T2 M6` in the middle, start it from Suivi. Expected: the program pauses at each `M6` with the tool change notice; the M5 button appears while the spindle turns; Reprendre asks for the tool and the Z zero, starts the spindle again at the programmed speed with a 3 s dwell, then the program continues to `M30` and Suivi shows "Terminé".
   2. **Z zero with the plate, in the air.** During the second `M6` pause, hold the touch plate under the tool by hand, enter its thickness and 20 mm of search in "Zéro Z avec une plaque", confirm. Expected: a 100 mm/min descent, a 1 mm back-off, a 25 mm/min touch, the plate top reading Z = thickness in the Machine screen, the tool 5 mm above it. Then test the two failure paths: start the probe with the plate already touching (must be refused: "déjà en contact"), and start it with the plate out of reach (must end in `ALARM:5`, explained in Suivi; stop the job, `$X`, home again if the board asks). Check with `$G` in CNCjs that `G90` and `G21` are still active after each probe.
   3. **Stop and resume from a line, in the air.** Stop the same program mid-way, read the suggested line in "Reprendre à une ligne…", check it, load it, start it. Expected: rise to the clearance height, rapid over the XY start, spindle restart, slow plunge, then the program runs to its end. Compare the path with the preview trail.
   4. **Same three steps on a piece of scrap**, spindle on, feed override at 50 % for the first run. Measure the Z zero error after a tool change with a dial or by a touch cut: the plate thickness entered must match the plate.
   5. Record each run as asked under "Reporting results", including the `$$` backup from the commissioning assistant, and the Suivi journal export.
10. Supervised validation of real jogging and work origins (F1, 2026-10 audit), before anyone sets `"touch": {"motion": {"enabled": true}}` in `.cncrc` for production. Two people: one at the tablet, one with a hand on the emergency stop. Spindle off, no tool or a blunt one, no stock, clamps removed. Everything below has only run against fake controllers and the Grbl 1.1h simulator.
    0. **Travel convention and position reports, BEFORE enabling `touch.motion.enabled` anywhere.** With the setting still off:
       - Keep `$10=1` (or 3): Grbl must report MPos. The server trusts machine positions only from MPos reports, or from WPos reports once a WCO has been received since the board started; a firmware that changes its work offset without sending WCO in the next report (not Grbl 1.1) would still mislead it, so `$10=1` is required on this machine. Note `$10` in the report.
       - Home (`$H`) from the classic interface and read the MPos of every axis, with `$23` and `$130-$132` noted. The server assumes standard Grbl 1.1: after homing, MPos lies in [-$13x, 0]; for an axis whose `$23` bit is set it also accepts [0, $13x] (Grbl_ESP32 with `home_mpos` 0, or `HOMING_FORCE_SET_ORIGIN`) and then only moves by distances safe in both. Jog each axis by hand (classic interface, low feed) to both ends and record the MPos at each end. If the MPos range of any axis is not one of those two intervals (a non-zero Grbl_ESP32 `home_mpos`, a pull-off outside the travel, another firmware), STOP: real motion stays disabled on this machine until the server's envelope is adapted and re-verified.
       - A jog never lasts more than 60 s at the chosen feed: hold a continuous jog at a slow feed and check that it stops by itself after 60 s.
    1. Preconditions: Grbl_ESP32 banner seen (`capabilities.jog.supported` true), `$13=0` (the server refuses real moves otherwise), `$20=1` (soft limits) and hard limits as configured, `$110-$112` and `$130-$132` read and correct. Note the values in the report. Enable the setting on the test bench only, restart CNCjs.
    2. Without homing: the continuous button must stay unavailable; a 10 mm step must be refused; 0.01, 0.1 and 1 mm steps on each axis and direction must move by that amount (dial indicator or ruler on X/Y, feeler on Z). Check the sign of every axis against the machine.
    3. Home (`$H`) and check the MPos against the record of step 0.
    4. Continuous jog at 200 mm/min, then at the maximum offered: hold, release → the machine stops within a few millimetres. Repeat with: finger sliding off the button (`pointercancel`), switching app or tab (blur, hidden page), locking the tablet, closing the browser tab.
    5. Network loss while holding: turn the tablet's Wi-Fi off (or pull the access point) during a continuous jog. Expected stop within about 0.3 s plus deceleration (keepalive every 100 ms, cancel after 250 ms without one). Measure and record it.
    6. Approach each end of travel with a continuous jog: the move must stop about 1 mm before the soft limit, with no `ALARM:2`.
    7. USB/serial cut while jogging (only at low feed, far from the ends): the machine keeps going until the end of the bounded `$J`. Confirm the distance matches the documented bound (distance to the travel end minus 1 mm, and at most 60 s at the feed); this is the case the server cannot stop.
    8. With the spindle turning (`M3` from the classic interface, at the minimum speed): a continuous jog must be refused and steps limited to 0.1 mm.
    9. Takeover: a second tablet takes control with a reason while the first holds a jog → the jog stops. A third client's Stop or Pause works at any time.
    10. Work origin: G54 then G55, set X, then Y, then Z at a marked point (ticket, then "Confirmer l'origine"); check `$#` and the WPos shown; move away and back with G0 in the classic interface to confirm. Refused during a job, an alarm, a pause.
    11. Report: firmware, settings, MPos records of step 0, measured stop distances and delays, any surprise. Only then may the owner enable `touch.motion.enabled` on the production machine.
11. Control ownership with two devices (F5). Tablet A and a second browser B (another tablet, or a PC on `/touch/`), both signed in, machine at rest:
    1. A loads a file: the strip shows "Cet appareil" on A and A's label on B. B's load, start, homing or unlock is refused with A's name; B's Pause, Stop and M5 work. The classic CNCjs page on a PC is refused the same way for commands that move the machine (a line in its console).
    2. B takes over with a reason: A shows "Pilotage repris par « B »" once; the history (Journal → Serveur) records the takeover.
    3. Close A's page: after 60 s the port is free. Reopen A: it does not get the port back by itself.
    4. Leave the owner's page open and the machine at rest for 5 minutes: the port is released ("Libéré après 5 min d'inactivité"). Repeat with a job that ends by itself: the lease is kept 5 minutes after the end, not released at once. Nothing is ever transferred or resumed without an explicit action.
    5. Turn A's Wi-Fi off for 30 s during a job, then on: A gets its stream back, keeps the lease, and nothing restarts.
12. Program check and history (F2, F4). Before any homing, the start confirmation shows "non vérifié"; after `$H`, a program inside the travel shows "dans la course" and a program 10 mm beyond `$130` shows "HORS COURSE" (a warning: the start stays possible). Check one program with `G53` moves. Restart CNCjs: Journal → Serveur still lists the previous jobs with their file and fingerprint.
13. Declared provenance (F6). Probe a grid with the CNCjs Autolevel widget, download the compensated file and the `.probe` grid, upload the compensated file to the library and fill in its provenance. Then change the work origin by more than 0.05 mm, or select another WCS: Fichiers must warn. Replace the original file: Fichiers must say the original changed. Touch adds no compensation: compare the compensated file with the Autolevel widget's own output.
14. Resume after a unit or WCS change (A1), in the air. A program starting in `G21`, switching to `G20` before the resume line: the converted preamble (for example `G0 Z0.1969` for 5 mm) must be accepted by Grbl_ESP32 and rise to the expected height. A program that changes from G54 to G55 before the resume line must be refused unless X, Y and Z are given again under G55.
15. Host commands (A3). With update, restart and shutdown commands configured in CNCjs (Settings → Commands): each is refused (409) during a job, a pause, a homing, a plate probe and a load, from the tablet and from the classic page; a disabled command answers 403. While a sensitive command runs, the tablet shows "Commande système en cours" and refuses machine actions; Pause and Stop stay available. Write the command itself in `.cncrc` (`sudo shutdown -h now`), not a wrapper script: a script called by its name is not recognised as sensitive.
